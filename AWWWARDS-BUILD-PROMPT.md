# CIA LUXURY FLEETS — AWWWARDS BUILD PROMPT (Visuals-First Edition)

> Generated by composing the `awwwards`, `motion-framer`, and `ui-ux-pro-max`
> skills against the v3 Master Brief + Motion Edition. This is the elite spec:
> **photography is the product, words are captions, motion is the brand voice.**
> One sentence describes the site: *a cinematic scroll through a fleet of elite
> vehicles where every gear change is a scene cut and not one word is unearned.*

---

## PHASE 1 — THE BRIEF (locked)

- **Purpose / audience:** A Port Harcourt luxury-rental marque. The person who
  screenshots this is a buyer deciding who arrives at their event. They screenshot
  the *car*, not the copy.
- **Register:** **Brand** — design IS the product. (awwwards routing.)
- **Aesthetic direction (one extreme, committed):** **Dark Marque Editorial** —
  cinematic near-black that breathes, full-bleed automotive photography, marque-level
  restraint, a single amber-gold signal colour.
- **The ONE unforgettable thing:** the **hero car as a living canvas** — a fixed,
  parallax-reactive, Ken-Burns photograph the entire page scrolls over, with a
  `₦0 → 70,000 /day` counter igniting on load. Runner-up signature: the fleet
  carousel where the active car *owns the viewport* and the photo morphs between
  vehicles.
- **Constraints:** Next.js 15 / React 19 / TS strict · Vercel · Lighthouse
  Perf ≥ 90, A11y ≥ 95, SEO ≥ 95 · AA contrast · reduced-motion honoured · 360px floor.

## PHASE 2 — PALETTE (OKLCH, tokenised — no raw hex in components)

Commitment level: **Restrained** (tinted near-black surfaces + one accent ≤ 10%).
Every neutral is tinted toward the brand hue (chroma 0.008–0.012); chroma falls as
lightness approaches 0.

```
--bg          oklch(0.10 0.008 65)   /* warm near-black, the living field */
--surface-1   oklch(0.14 0.008 65)
--surface-2   oklch(0.18 0.010 65)
--ink         oklch(0.96 0.006 75)
--ink-2       oklch(0.74 0.010 70)
--ink-3       oklch(0.62 0.012 68)   /* muted — still ≥ AA on bg */
--accent      oklch(0.78 0.14 72)    /* amber-gold — the ONLY saturated colour */
--accent-dim  oklch(0.60 0.10 72)
--accent-glow oklch(0.78 0.14 72 / 0.15)
```

The background is **never flat** (awwwards anti-pattern): 4% SVG grain overlay
always on, an ambient accent-glow bloom in the dark field, and in the hero the car
photo itself is the canvas. Radius minimal (2 / 4 / 8px) — this is not a rounded site.

## PHASE 4 — COMPOSITION (each gear a different layout shape)

Typography (never Inter/Roboto/Space Grotesk): **Cormorant Garamond** (display) ·
**DM Sans** (body/UI) · **DM Mono** (specs/stats), self-hosted via `next/font`.
Type IS the design: 72–96px serif headlines, ≤ 5 words; body ≤ 2 sentences; specs in mono.

The page is **7 gears**, each owning its viewport with a distinct shape — no two
adjacent gears repeat a shape (the Repetition Test is a build gate):

| Gear | Name | Layout shape | Photography role |
|------|------|--------------|------------------|
| 01 | Hero | Fixed full-bleed canvas, oversized serif, ₦ counter, cycling subline, 2 CTAs. No chrome. | The car IS the background |
| 02 | Trust | Full-width mono bar, vertical hairlines, count-up once. No cards. | none (silence) |
| 03 | Fleet | Full-viewport carousel — active car dominates, neighbours `scale .86 / opacity .35`; specs drawer; velocity marquee. | dominant surface |
| 04 | Services | 58/42 featured Security & Escort block + compact 4-icon row. | featured photo |
| 05 | Why CIA | 6-up spec-sheet grid, hairline dividers only. | none |
| 06 | Story | Giant faded numerals + connecting rule, then one centred italic testimonial. | none |
| 07 | Reserve | Split-panel: editorial contact + functional form. | none |

**Words-are-captions rule:** if a photo can do a sentence's job, delete the sentence.
Per-car copy = name + one ≤6-word line + `from ₦X/day`. Full specs only in the drawer.

## PHASE 5 — MOTION CALIBRATION

**Lens: Polish (Krehel)** — choreographed, measured, deliberate easing. Never bouncy,
never twitchy. Polish easing default `[0.22, 1, 0.36, 1]`; restraint `[0.4, 0, 0.2, 1]`.

**Library ownership (never two on one element):**

| Tool | Owns |
|------|------|
| GSAP + ScrollTrigger | The hero pinned timeline ONLY (the whole motion budget) |
| Framer Motion | Carousel morph, tabs (`layoutId`), specs drawer, hover variants, stagger reveals, testimonial word-reveal, magnetic CTA, cycling subline, form feedback, mouse-parallax/tilt |
| Custom rAF / CSS | Count-up (`easeOutCubic`), grain, ambient glow, scroll cue |

**Named springs:** snap `400/35` · reveal `300/28` · gesture `400/28` · hero `260/24`.

**Motion-meaning gate (ui-ux-pro-max rule):** every animation answers "what does this
mean?" in one sentence or it is cut. Stagger = "scan these together." Tilt/magnetic =
"this is alive, press it." Morph = "same element, it moved." Decoration without meaning = noise.

**Global rules:** `useReducedMotion()` at root → durations 0, no pin, no stagger, no
magnetic, no parallax, cycling shows phrase 1 static. Every `whileInView` is
`once: true`. No looping viewport animation. No `whileHover scale 1.05` on every card.
Exit at 60–70% of enter. One element animates per beat (stagger or sequence, not a blast).

## PHASE 6 — IMPLEMENTATION (Branch B: Next.js production)

Stack: Next.js 15 App Router · TS strict · Tailwind + CSS-var tokens · `next/font` ·
GSAP+ScrollTrigger (hero) · Lenis (gated) · Framer Motion · Embla (fleet) ·
react-hook-form + zod · `next/image` · lucide-react · Resend (optional). JSON-LD
`AutoRental` + OpenGraph + canonical.

**The signature moves (visuals-first):**

1. **Hero living canvas** — `position: fixed` car photo; GSAP pins `#gear-01` for
   180vh, scrubs Ken-Burns `scale 1→1.06` + fades headline/stat out. On load: char
   stagger headline, counter ignites, CTAs rise. **Mouse-parallax**: the photo drifts
   ±8–12px against the cursor (Framer `useSpring`) for living-field depth (Sui). LCP
   guard: hero text is plain HTML first; image `priority` + sized; libs mount after paint.

2. **Fleet carousel** — Embla owns drag; the active car is full-bleed, neighbours
   recede. Category tabs filter instantly with a `layoutId` underline. Specs drawer
   springs up (`reveal`). **Mouse-tilt** on the active frame (awwwards TiltCard recipe,
   `rotateX/Y ±6°`, perspective 1000) — premium and tactile. Velocity marquee between
   Fleet and Services (mobile: constant speed, damping 80).

3. **Magnetic primary CTAs** — real component (hooks-in-helper gotcha), ±12px cap.

4. **Testimonial** — one quote, word-by-word reveal, no card, no stars.

**Image discipline (§0 law):** every URL mechanically fetched (HTTP 200) AND visually
inspected before use; logged in `IMAGE-MANIFEST.md`. One consistent dark low-key grade
across all 11+ cars. Best-match placeholders logged in `SWAP-MANIFEST.md`.
